# Instant Productivity Suite

Build an AI-powered productivity application combining three core features:

Smart Email Generator

Generate professional emails from short user instructions.

Support different tones such as professional, friendly, concise, persuasive, and formal.

Allow users to edit, regenerate, copy, and refine generated emails.

Provide subject-line suggestions.

Include options to shorten, expand, simplify, or change the tone of an email.

Meeting Notes Summarizer

Allow users to paste or upload meeting notes/transcripts.

Automatically summarize the meeting into key discussion points.

Extract decisions, action items, deadlines, and important topics.

Organize summaries into clear sections.

Allow users to copy, edit, and regenerate summaries.

AI Task Planner & Scheduler

Allow users to enter tasks in natural language.

Use AI to break large tasks into smaller actionable steps.

Prioritize tasks based on urgency and importance.

Suggest realistic schedules and time blocks.

Include due dates, priorities, estimated durations, and task status.

Provide a daily and weekly schedule view.

Allow users to reschedule, edit, complete, and delete tasks.

Automatically reorganize the schedule when tasks change or deadlines move.

Authentication

Remove authentication completely. The application must not require login, signup, passwords, accounts, OAuth, or authentication screens. Users should be able to open the application and immediately use all three features.

UI/UX

Create a modern, clean, responsive dashboard with three primary sections:

Smart Email Generator

Meeting Notes Summarizer

AI Task Planner & Schedule

Use a simple navigation system, intuitive forms, clear AI-generated results, loading states, empty states, and helpful error messages. Make the interface responsive for desktop, tablet, and mobile.

The application should work as a seamless productivity workspace where users can move between email generation, meeting summarization, and task planning without authentication or account creation.
